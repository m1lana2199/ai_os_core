# ai_os_core Control Center ⚡️

Лёгкая и защищенная система управления и мониторинга процессов (Control Center), написанная на Rust с веб-интерфейсом на Tailwind CSS.

## 🚀 Что внутри?
- **Ядро на Rust**: высокая производительность и безопасность.
- **Живой мониторинг**: сбор метрик системы в реальном времени.
- **SPA Dashboard**: стильный интерфейс управления с кастомной иконкой.
